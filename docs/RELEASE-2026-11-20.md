# Android release - 2026-11-20

Built from branch `fix/android-lock-window-from-adhan`: the prayer-lock window
is now measured from the adhan, and the lock screen lets the display time out.
Only Android changed.

| Target | Version | Package |

| Chrome Web Store | 2.3.11 (unchanged) | - |

## What changed

- **Android, lock window from the adhan:** the lock runs from the prayer time,
  not from when it actually engaged. A lock delayed by a phone call (or a late
  notification tap) covers only what is left of the window, and nothing if the
  window is already over. The notification now carries the prayer time
  (`extra.when`) so a late tap computes the remaining window; the native
  scheduler keeps the original prayer time (`start`) when it re-queues a lock
  for a call, and stamps `unlockAt = start + duration` (less than 15 s left:
  the lock is dropped).
- **Android, screen timeout:** the lock screen no longer sets
  `FLAG_KEEP_SCREEN_ON`. It wakes the display once at prayer time
  (turn-screen-on is cleared after it is shown, so a watchdog re-launch never
  wakes a screen that timed out, and the watchdog skips re-launching while the
  screen is off), then the screen may turn off normally;
  `showWhenLocked` keeps the lock up when the phone is woken again.
