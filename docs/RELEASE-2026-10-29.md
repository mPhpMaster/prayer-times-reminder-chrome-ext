## Distribution

Windows installers are published under desktop-v1.0.15 so existing direct-install
update checks can find them. Shared Chrome, Android and Vencord packages use
release tag 2.3.10. Store upload/review/approval are separate states; a successful
local build or GitHub upload does not establish store approval.

Local build logs and packages: output/releases/2026-10-29/. Credentials, keystores,
private signing settings, browser sessions and other userplugins are excluded.
